# Derived data

`01_data_processed/` contains only the eight inputs required by the released environmental
frontier model and its tests. The demand files are hourly aggregates derived from the public trace.
Carbon, PUE, WUE, capacity, latency, energy, and water-stress files are explicit scenario inputs.

`03_results/` contains frozen outputs generated by the released Python code. Figure source tables
are rebuilt from those outputs by `02_code/build_ema_figure_source_data.py`.
