# Processed and derived data

`01_data_processed/` contains the exact scenario and processed-input tables used by the frozen calculations. `04_results/` contains policy metrics, dispatch records, sensitivity matrices, paired-block ranges, and QA records. `figures/` contains panel-level source CSVs and frozen exports.

No raw GenTD26 or Azure request trace is included. The archive preserves reproducibility of the reported calculations without republishing source traces.

Author-created derived tables and figure-source CSVs are released under CC BY
4.0, subject to the upstream boundary described in `DATA_SOURCES.md` and
`DATA_LICENSE.md`.
