# Data sources and access terms

This archive redistributes derived analysis inputs, not original request-level traces.

| Source | Archive content | Boundary |
| --- | --- | --- |
| Alibaba GenAI Serving Top-Down Dataset 2026 (GenTD26) | Hourly service-demand aggregates | Obtain the raw request trace from Alibaba Clusterdata; this archive does not grant additional rights in the source data. |
| National carbon-factor and infrastructure references | Ordinally aligned carbon and scenario tables | Scenario inputs, not contemporaneous operator or marginal-grid telemetry. |
| Aqueduct 4.0 baseline water stress | Four-region categorical screening table | Location screen only; not a hydrologic-damage multiplier. |
| PUE, WUE, capacity, latency, and energy layers | Study-specific scenario tables | Explicit model inputs, not named-facility measurements. |

The archive excludes raw request records, operator telemetry, credentials, submission documents,
and private working files. Author-created derived tables are CC BY 4.0 subject to upstream terms.
