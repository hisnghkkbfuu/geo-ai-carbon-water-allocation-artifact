This archive distributes processed, derived analysis inputs and does not redistribute original request-level traces.

| Source | Archive content | Access and attribution |
| --- | --- | --- |
| Alibaba GenAI Serving Top-Down Dataset 2026 (GenTD26) | Hourly and request-type aggregates only | Obtain the original data from Alibaba Clusterdata. The repository describes research/study use; this archive does not assert a standard open-source or Creative Commons licence. |
| Azure LLM Inference Dataset 2024 | Derived hourly token/service aggregates only | Obtain original data from the official Azure Public Dataset release. The source is CC BY 4.0; cite the associated DynamoLLM study. |
| Vidur | Derived execution-time lookup and grid manifest | Obtain the implementation and metrics from the official Microsoft repository. No Vidur source code is redistributed. |
| Carbon, PUE, WUE, capacity, and water-stress layers | Study-specific scenario tables | Explicit analysis inputs and derived scenarios. They are not operator telemetry. |
